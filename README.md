# عقل فعّال (Active Mind) — static GitHub Pages mirror

Static mirror of https://do-craft.grok.me built for the `/do-craft/` sub-path.
Live: https://theaterstage.github.io/do-craft/

- `2141` HTML routes (every route has its own index.html), `/assets/*`, images, fonts, manifest, `404.html`, `.nojekyll`.
- New sections (all client-side, progress in localStorage): `/restore/` (استعادة الدوبامين: 30 stages x 9 exercises), `/iq/` (تمارين زيادة الذكاء: 20 x 10), `/brain/` (تمارين مقاومة تبلد الدماغ: 30 x 9), `/proc/` (مواجهة المماطلة: 18 x 11, Duolingo-style path), `/dragon/` (ترويض التنين الخامل: 22 x 16, Duolingo-style path) and `/tools/` (أدوات المساعدة). Exercises live at `/train/<id>`. They are generated by `generator/` and verified by `npm test` (`tests/verify-exercises.mjs`); `tests/e2e-new.mjs` is the headless click-through.
- Client-side only: the app has no backend, WebSocket, EventSource or `/api` calls; all progress is stored in `localStorage`.
- Rebuild for another base path with `build.py` (`BASE=/other SITE=https://owner.github.io python3 build.py`).
